# Square Root Calculator – Square Roots, Cube Roots & Powers Guide

In mathematics, roots and exponents are inverse operations. Finding a **square root** answers the question: *"What number multiplied by itself yields this value?"*

This calculator supports **3 modes**:
1. **Square Root Mode (sqrt(x))**: Computes x^0.5.
2. **Cube Root Mode (sqrt[3]{x})**: Computes x^1/3.
3. **Power Mode (x^p)**: Computes x raised to any exponent power p.

---

### Understanding Square Roots & Exponents

#### 1. Square Roots (sqrt(x))
The principal square root of a non-negative number x is the unique non-negative number y such that:
y × y = y^2 = x
In exponent notation, a square root is written as:
sqrt(x) = x^0.5 = x^1/2

#### 2. Perfect Squares vs. Non-Perfect Squares
* **Perfect Squares**: Integers whose square roots are whole numbers ($1, 4, 9, 16, 25, 36, 49, 64, 81, 100$).
  - Example: sqrt(9) = 3 because 3 × 3 = 9$.
  - Example: sqrt(25) = 5 because 5 × 5 = 25$.
* **Non-Perfect Squares**: Numbers whose square roots are irrational decimals.
  - Example: sqrt(50) ≈ 7.071068. Since 50$ lies between perfect squares 49$ (sqrt(49)=7) and 64$ (sqrt(64)=8), its square root lies just above 7$.

#### 3. Cube Roots (sqrt[3]{x})
A cube root finds a value y that, when multiplied by itself three times, equals x:
y × y × y = y^3 = x implies sqrt[3]{x} = x^1/3
* Example: sqrt[3]{27} = 3 because 3 × 3 × 3 = 27$.

#### 4. Custom Exponent Power Mode (x^p)
Power mode raises base number x to exponent power p:
* Integer Exponents: 2^5 = 2 × 2 × 2 × 2 × 2 = 32$.
* Fractional Exponents: 9^0.5 = sqrt(9) = 3$.

### Real Domain Limitations

* **Negative Numbers in Real Math**: The calculator is designed for real numbers. In real math, square roots of negative numbers (e.g., sqrt(-9)) are undefined because no real number multiplied by itself equals a negative number.

### Frequently Asked Questions (FAQ)

* **Q1: What is a square root?**
  * A1: The square root of a number x is a value y such that y × y = x. It is written using the radical symbol √x or as an exponent x^0.5.
* **Q2: What is the difference between a square root and a cube root?**
  * A2: A square root (√x) finds a number that multiplies by itself twice to equal x (y² = x). A cube root (³√x) finds a number that multiplies by itself three times to equal x (y³ = x).
* **Q3: Can negative numbers have square roots in real math?**
  * A3: In the real number system, negative numbers do not have real square roots because squaring any real number (positive or negative) yields a positive result.
