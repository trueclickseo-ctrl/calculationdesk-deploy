# Chemical Name Lookup

Enter a molecular formula, and this tool looks up its corresponding common or chemical name from a reference list of everyday compounds.

## How it works

This is a direct lookup tool rather than a calculation — it checks the entered formula (normalized to lowercase, with extra spaces trimmed) against a stored list of 10 common compounds: NaCl (Sodium Chloride), H2O (Water), CO2 (Carbon Dioxide), NaOH (Sodium Hydroxide), HCl (Hydrochloric Acid), C6H12O6 (Glucose), NH3 (Ammonia), CH4 (Methane), CaCO3 (Calcium Carbonate), and H2SO4 (Sulfuric Acid).

Enter "NaCl" and the tool returns Sodium Chloride, the chemical name for common table salt.

## Formal names vs. common names

Some compounds carry both a systematic chemical name and a familiar common name. Water (H2O), for example, has the technically valid systematic name "dihydrogen monoxide" if chemical naming conventions are applied literally to its formula, though "water" is what's used everywhere in practice — this tool notes both where relevant, since either can come up depending on context.

## What this tool doesn't cover

This lookup is limited to the 10 formulas listed above — it's a curated reference for common compounds, not a comprehensive chemical database. A formula outside this list won't return a match, and identifying it would require a broader chemistry reference or applying formal IUPAC nomenclature rules directly.
