# Percentage Calculator – 4-in-1 Problem Solver Guide

Percentage calculations are essential for everyday finance, shopping discounts, tax additions, and mathematical analysis.

This calculator supports **4 distinct percentage modules**, solving each operation with exact mathematical formulas.

---

### How Each Percentage Module Works

#### Module 1: What is $X\%$ of $Y$?
Calculates the numerical value of a percentage portion:

$$\text{Value} = \left(\frac{X}{100}\right) \times Y$$

#### Module 2: $X$ is what percentage of $Y$?
Calculates the ratio percentage of a part relative to the whole:

$$\text{Percentage (\%)} = \left(\frac{X}{Y}\right) \times 100$$

#### Module 3: Percentage Change from $X$ to $Y$
Calculates relative percentage increase or decrease:

$$\text{Percentage Change (\%)} = \left(\frac{Y - X}{X}\right) \times 100$$

#### Module 4: Add or Subtract $X\%$ to/from $Y$
Calculates adjusted values after applying percentage markups or discounts:

$$\text{Value Added} = Y \times \left(1 + \frac{X}{100}\right)$$

$$\text{Value Subtracted} = Y \times \left(1 - \frac{X}{100}\right)$$

---

### Step-by-Step Worked Numerical Examples (Verified against Code)

#### Example 1: Module 1 (15% of $200)
- **Calculation**: $(15 / 100) \times 200 = 0.15 \times 200 = \mathbf{\$30.00}$

#### Example 2: Module 2 ($40 out of $200)
- **Calculation**: $(40 / 200) \times 100 = 0.20 \times 100 = \mathbf{20.00\%}$

#### Example 3: Module 3 (Change from $150 to $180)
- **Calculation**: $[(180 - 150) / 150] \times 100 = (30 / 150) \times 100 = \mathbf{+20.00\%}$

#### Example 4: Module 4 (Add/Subtract 15% to/from $200)
- **Added**: $200 \times (1 + 0.15) = \mathbf{\$230.00}$
- **Subtracted**: $200 \times (1 - 0.15) = \mathbf{\$170.00}$

### Frequently Asked Questions (FAQ)

* **Q1: What is the difference between percentage change and absolute change?**
  * A1: Absolute change is the simple difference between two numbers ($180 - 150 = 30$). Percentage change measures that difference relative to the starting value ($\frac{30}{150} \times 100 = 20\%$).
