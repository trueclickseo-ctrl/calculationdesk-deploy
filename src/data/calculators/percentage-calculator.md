# Percentage Calculator – 4-in-1 Problem Solver Guide

Percentage calculations come up constantly in everyday finance, shopping discounts, tax additions, and academic math. This calculator supports four distinct percentage modules, each solving a specific type of question with the correct formula.

## How Each Percentage Module Works

**Module 1 — What is X% of Y?**

$$\text{Value} = \frac{X}{100} \times Y$$

**Module 2 — X is what percentage of Y?**

$$\text{Percentage (\%)} = \frac{X}{Y} \times 100$$

**Module 3 — Percentage change from X to Y**

$$\text{Percentage Change (\%)} = \frac{Y - X}{X} \times 100$$

**Module 4 — Add or subtract X% to/from Y**

$$\text{Value Added} = Y \times \left(1 + \frac{X}{100}\right) \qquad \text{Value Subtracted} = Y \times \left(1 - \frac{X}{100}\right)$$

## Worked Examples

1. **Module 1** (15% of 200): $\dfrac{15}{100} \times 200 = 30.00$
2. **Module 2** (40 out of 200): $\dfrac{40}{200} \times 100 = 20.00\%$
3. **Module 3** (change from 150 to 180): $\dfrac{180 - 150}{150} \times 100 = +20.00\%$
4. **Module 4** (add/subtract 15% to/from 200): Added = $200 \times 1.15 = 230.00$; Subtracted = $200 \times 0.85 = 170.00$
