# Scientific Calculator – Online TI-84 Style Math Workspace

The **Scientific Calculator** provides a digital mathematical workspace styled after classic handheld TI-84 calculators. It allows students and researchers to evaluate complex arithmetic, trigonometric, logarithmic, and exponential expressions.

---

### Verified Keypad Functions & Supported Operations

#### 1. Basic Arithmetic & Algebra
- **Addition (+), Subtraction (−), Multiplication (×), Division (÷)**
- **Parentheses `(` and `)`**: Used to group terms and establish operation precedence.
- **Powers (`^`)**: Computes exponentiation (e.g. `2^5 = 32`).
- **Square (`x²`)**: Squares the entered number or expression (appends `^2`).
- **Reciprocal (`1/x` or `x⁻¹`)**: Appends `1/` for reciprocal calculations.
- **Square Root (`√`)**: Evaluates square roots using `sqrt(` syntax (e.g. `sqrt(49) = 7`).
- **Factorial (`!`)**: Computes integer factorials (e.g. `5! = 120`).

#### 2. Trigonometric Functions
- **`sin`**: Calculates sine in **radians** (e.g. `sin(0.5) ≈ 0.47942554`).
- **`cos`**: Calculates cosine in **radians** (e.g. `cos(0) = 1`).
- **`tan`**: Calculates tangent in **radians** (e.g. `tan(0) = 0`).

*Note on Angle Mode: Trigonometric calculations in this tool operate strictly in **radians**.*

#### 3. Logarithms & Constants
- **`log`**: Common logarithm (base 10). For example, `log(100) = 2`.
- **`ln`**: Natural logarithm (base $e$). For example, `ln(e) = 1`.
- **Mathematical Constants**: Supports `π` ($\approx 3.14159265$) and `e` ($\approx 2.71828183$).

---

### Step-by-Step Worked Numerical Examples (Verified against Code)

1. **Power Calculation (`2^5`)**:
   - Keypress sequence: `2`, `^`, `5`, `enter`.
   - Result = **32**

2. **Square Root (`sqrt(49)`)**:
   - Keypress sequence: `√`, `49`, `)`, `enter`.
   - Result = **7**

3. **Trigonometric Sine in Radians (`sin(0.5)`)**:
   - Keypress sequence: `sin`, `0.5`, `)`, `enter`.
   - Result = **0.47942554**

4. **Natural Logarithm of $e$ (`ln(e)`)**:
   - Keypress sequence: `ln`, `e`, `)`, `enter`.
   - Result = **1**

### Interface Controls & Calculation Tape

- **Digital Tape Records**: Located in the side panel, this feature records up to 30 past equations. You can copy results, download history to a text file, or print your tape.
- **Device Theme Toggle**: Use the sun/moon icon on the top-right of the calculator frame to switch between dark and light device aesthetics.

### Frequently Asked Questions (FAQ)

* **Q1: Does this scientific calculator use degrees or radians for trigonometry?**
  * A1: Trigonometric functions (sin, cos, tan) in this calculator default to using radians, which is the standard mathematical convention in calculus and analysis.
* **Q2: What mathematical functions are supported?**
  * A2: Supported operations include addition (+), subtraction (-), multiplication (×), division (÷), exponents (^), square roots (sqrt), factorials (!), trigonometry (sin, cos, tan), logarithms (log base 10, natural log ln), and mathematical constants (π, e).
