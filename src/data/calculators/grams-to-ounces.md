# Grams to Ounces Converter

Enter a mass in grams, and this calculator converts it into the equivalent mass in ounces.

## Formula

**Ounces = Grams × 0.035274**, since one avoirdupois ounce equals exactly 28.349523125 grams.

100 grams converts to 100 × 0.035274 ≈ 3.527 ounces.

## Not the same ounce used for gold and silver

This calculator converts using the avoirdupois ounce, the standard everyday weight unit used for food and general goods. Precious metals like gold and silver instead use the troy ounce, which is heavier at about 31.1035 grams per troy ounce. Using this everyday conversion for a precious metal weight would understate the actual troy-ounce equivalent, since the two systems define "ounce" differently.

## A precise, exact conversion

Unlike some time-based unit conversions that rely on averages, this one is exact — the international definition ties one avoirdupois ounce to precisely 28.349523125 grams, so the only imprecision in a result comes from how many decimal places it's rounded to for display, not from the underlying conversion ratio itself.
